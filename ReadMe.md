# MAXGPT

MAXGPT is a GenAI-powered program that combines **SQLAlchemy**, **Groq LLM**, and **Pandas** to dynamically execute database queries from natural language input. It also supports **graph generation** and **archiving of results**, making it a versatile tool for data analysts, engineers, and researchers.

---

Features
- **Natural Language to SQL**: Convert human language queries into executable SQLAlchemy queries.
- **Groq LLM Integration**: Leverages Groq’s language model for query interpretation and optimization.
- **Data Analysis with Pandas**: Processes query results for advanced analytics.
- **Graph Generation**: Automatically creates visualizations from query outputs.
- **Archiving**: Saves query results and graphs for future reference.
